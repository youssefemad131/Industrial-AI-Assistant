# FactoryLens AI

Team Names: [Raghda Badran Hassan, Shahd Amar Shedid, Nada Mahmoud Ahmed, Abdelrahman
Magdy Amin, Youssef Emad Samuel ]

Guided quality-investigation assistant for factory QC engineers (HCAI course project, AI track).
Principle tested: **Explainability**. **All data is synthetic** (no real factory data).

Every answer has three labelled blocks: **Observed fact / Hypothesis / Missing data**, plus source, time range and a next check.
The engineer decides; the bot never confirms a root cause, never approves a production decision, never analyses individual workers.

## How it works (matches the Week 5 flow)
| Part | File | Job |
|---|---|---|
| Orchestrator | `backend/engine.py` (`FactoryLens.ask`) | routes: answer / clarify (E1) / fallback (E2) / partial data (E3) / handover / refusal; 2 fallbacks in a row -> handover (E6) |
| Answer builder | `engine.py` (`a_*` methods) | all numbers come from pandas on the CSVs; hypotheses come only from maintenance notes / supplier status |
| Validator | `engine.py` (`validate_numbers`) | blocks any number that was not computed (E4: facts-only fallback) |
| Data | `backend/data/*.csv` | synthetic, generated by `backend/generate_data.py` (seed 42) |
| API | `backend/main.py` | FastAPI `POST /chat`, `GET /health` |
| Terminal chat | `backend/cli.py` | used for the demo video |
| Logger | `engine.py` (`_log`) | logs intent/type/latency only; no question text, no personal data |

## Run it
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 1) Terminal chat (what the demo video shows)
python -m backend.cli

# 2) HTTP API
uvicorn backend.main:app --reload
curl -X POST http://127.0.0.1:8000/chat -H "Content-Type: application/json" \
     -d '{"question":"Did defects go up this week?","session_id":"demo"}'
```
Re-generate the data (optional, same result every time): `python -m backend.generate_data`

## Tests (the test set)
```bash
python tests/run_testset.py --show     # runs all 32 prompts from test_set/ through the real engine
python tests/make_testset_xlsx.py      # rebuilds test_set/FactoryLens_Test_Set.xlsx
```

## Optional: LLM wording (off by default)
By default replies are deterministic, so the demo is repeatable. With `USE_LLM=1` the hosted model may only **reword**
an already-computed answer; if it adds any number that was not computed, the validator discards its text.
```bash
export ANTHROPIC_API_KEY=...   # never commit this; .env is git-ignored
export USE_LLM=1
```

## Limits (honest scope)
- Synthetic data for 18-29 Oct 2026 only; no SAP / live machine connection.
- No Streamlit UI yet (terminal + API only).
- Arabic input is detected and block labels are bilingual; the body text of answers is English.
